// The fact base of codespec query: every relation, its fields in order and their types.
// A node is <module path>.<function key>#<index path>; a position is <module path>/<file>:<line>.

// From the documents, every reader.

module{path: string, name: string, lang: string, reader: string, version: string}
    one per document; path is its import path, or its name when it has none
func{id: node, module: string, name: string, recv: string, exported: bool, kind: string, pos: string, line: int}
    every function: kind func, method, init, lambda (id the literal's node) or opaque (no body read)
param{func: node, index: int, name: string, t: type}
    every parameter; the receiver of a method at index -1
result{func: node, index: int, name: string, t: type}
    every result type
raises{func: node, t: type}
    every extern type a function lists in raises: what its raise statements and the functions it calls raise, outside its results
stmt{id: node, func: node, kind: string, op: string, pos: string, line: int, parent: node}
    every statement; func the declared function holding it, parent the node it sits in, op an assign's operator
expr{id: node, func: node, kind: string, t: type, stmt: node, parent: node, slot: string, index: int, op: string, name: string, value: string, x: node, y: node}
    every expression: slot and index its place in parent (index -1 outside a list); x and y its operands
let_name{stmt: node, index: int, name: string, last: bool}
    every name a let binds
field_init{expr: node, index: int, name: string, value: node}
    every field of a struct literal
call{site: node, func: node, kind: string, callee: string, path: string, type: string, name: string, recv: node, args: int, pos: string, line: int, listed: bool}
    every call, read or listed (foreign statements, opaque functions): kind func, method, iface, value or ref (a function used as a value); callee <path>.<name> or <path>.<type>.<name>
call_by{site: node, by: string}
    every listed call whose target a convention gave, not the source language's type information: by the convention the reader names (Groovy: grails-gorm, grails-service-field); calls links such a call as any other
type{id: type, kind: string, name: string, path: string, bits: int, signed: bool, elem: type, key: type, fields: int, under: type, decl: string}
    every type the documents name or declare; bits and signed of an integer, a named integer resolved; decl the kind of a declared type
type_elem{type: type, index: int, t: type, last: bool}
    every element of a tuple type
type_field{type: type, index: int, name: string, t: type}
    every field of a declared struct
fact{kind: string, module: string, item: string}
    the facts of codespec pass: fallible, comma_ok, shared, messages, read_only, displays, unordered_iteration
refusal{module: string, pos: string, what: string, reason: string}
    every refusal a reader recorded
foreign{stmt: node, lang: string, reason: string, calls_known: bool}
    every foreign statement; calls_known when the reader listed its calls
unknown{func: node, site: node, pos: string, reason: string}
    every place the fact base cannot see: an opaque function, a foreign statement without a call list, a call of a function value or through an interface
reader_has{lang: string, part: string}
    what the readers of a language fill: bodies, calls, externs, dispatch
method_set{t: type, name: string, sig: string, target: string}
    the method sets the reader listed, the target as a callee

// Derived per read body.

contains{outer: node, inner: node}
    inner lies inside outer, at any depth
cfg_next{from: node, to: node}
    control may pass from one statement to the next
entry{func: node, node: node}
    the first statement of a body (a function or a function literal)
exit{func: node, node: node}
    every return or raise of a body, every statement calling a function that lists raises, and every statement that falls off its end
dominates{a: node, b: node}
    every path from the entry to b passes a; a dominates itself
postdominates{a: node, b: node}
    every path from b to an exit passes a; a postdominates itself
guards{cond: node, node: node, branch: bool}
    node runs only when cond, the condition of an if or a for, is branch
def{var: string, node: node}
    node sets the local var (<body>$<name>): let, var, assign, incr, decr, for_range, lookup_else; a parameter at its body
use{var: string, node: node}
    the expression node reads the local var
flows{from: node, to: node}
    the definition at from reaches the use at to
value{expr: node, var: string}
    the expression is the local var

// From codespec's graph.

calls{site: node, target: node}
    a call linked to the function of the set it names: a function, a method of a declared type, a function used as a value
reaches{from: node, to: node}
    to is reached from from by one or more calls
reaches_path{from: node, to: node, path: list}
    reaches with its witness: the functions from from to to, the least of the shortest call paths by function id
reached{func: node}
    codespec reach (rta) reaches func from every main.main and init
scc{func: node, comp: node}
    the strongly connected components of the functions over calls; comp the least function id of func's component
effect{func: node, effect: string, pos: string}
    codespec effects: func may have the effect through the call at pos (its own, or one leading there), from the summaries and the barrier given
syscall{func: node, name: string, pos: string}
    codespec effects: func may make the syscall through the call at pos, from the barrier given
makes{func: node, t: type}
    func's body makes a value of the named type t: a struct literal, a conversion, a zero value, a literal or constant, a var, an error wrapped, a listed new; a method makes its receiver's type; making a struct makes the named types its fields hold by value
implements{t: type, iface: string}
    the method set of t holds every method of the interface iface with an identical signature (the CHA test); iface a declared interface or one a call list names
