All five sidebar groups are open, which is 24 links. At 1366x768 and 1280x720 the sidebar ends near
"Map a repository to syscalls". The Reference group, and the highlighted current page on any Reference
page, are below its fold. The order also works against a first visit:

- Vision comes before Getting started.
- Status sits in Start here.
- The four generated Examples (37 % of the site's words) come before Concepts and Guides.

Effect: on a Reference page the sidebar doesn't show where the reader is. A new reader meets
philosophy, a status table and four long generated walkthroughs before the first concept.

Fix direction (one line): collapse all groups except the current one, and order the groups Start
(index, Getting started), Guides, Concepts, Examples, Reference, with Vision and Status at the end.

Severity S3: the navbar and breadcrumbs still give the location, and every page is reachable.

Fixed in R-03: groups ordered Start here, Guides, Concepts, Examples, Reference, Project (Vision, Status); every group but Start here collapsed, autoCollapseCategories on.
