Since the C reader and writer columns were added, the support matrix is wider than its column at
1440x900, 1366x768 and 1280x720, so it scrolls sideways at every desktop width. Each feature row's
description is cut to one line with an ellipsis, so a reader can't read it in place.

Effect: a reader comparing languages scrolls sideways and hovers or opens each row to read what a
feature is.

Fix direction (one line): drop the description column to a second line under the feature id, or
fold it, in `website/src/components/SupportMatrix`.

Severity S3: one page, its content all reachable.
