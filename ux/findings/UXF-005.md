`/codespec/search`, the full results page of `@easyops-cn/docusaurus-search-local` (added for UXF-001),
renders its query input with a hard-coded `autoFocus`. Focus starts in the input, so the first Tab
moves past it to the footer instead of to "Skip to main content", at both gating viewports and in
both themes. Every other check passes on the page.

Effect: a keyboard user who opens the results page lands in the query box, which is what the page is
for; the skip link is reachable with Shift+Tab. Nothing is blocked.

Fix direction (one line): wrap the plugin's `SearchPage` theme component so focus starts at the top
of the page (or upstream an option to turn `autoFocus` off), then drop this waiver.

Severity S3: one page, one keyboard check, the page's own purpose served.
