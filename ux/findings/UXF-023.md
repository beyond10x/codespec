Every hand-written page has a header card whose source line says where its output came from. On Use cases, Getting started and two guides the first paragraph then says the same thing
again: installed codespec, a clone or empty directory, output pasted from that run. Read a Quarkus
project and Add an adapter state it once, in the card.

Effect: the first thing under the card on four pages is a sentence the reader has just read.
It goes against the loop's goal of less content.

Fix direction (one line): keep the run clause in the card and cut the paragraph to what the card
does not say (path shortening, `CODESPEC_ADAPTERS`).

Severity S3: costs reading time, blocks nothing.

Fixed in R-06: on Use cases, Getting started and the two guides the first paragraph keeps only what the header card does not say (path shortening, `CODESPEC_ADAPTERS`, the `jq` lines, the install link). Use cases' card gains "in a clone", which only its paragraph said.
