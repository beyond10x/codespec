On a docs site the commands and their output are the key data. Code blocks are set at 13.12 px next to
17.28 px body text, a 0.76 ratio. The page outline (TOC) and breadcrumbs are 12.8 px. The hero source
line is 13.12 px in the muted colour. Contrast passes in both themes (axe 0 serious).

Effect: the reader copies commands from the smallest text on the page.

Fix direction (one line): raise `--ifm-code-font-size` so code blocks are at least 14 px, and the TOC
to 14 px (`website/src/css/custom.css`).

Severity S3: readable, but below the 14 px floor the heuristic sets.

Fixed in R-03: code blocks 0.9rem (14.4px), the table of contents 0.875rem (14px).
