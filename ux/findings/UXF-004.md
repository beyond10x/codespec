On `/codespec/docs/reference/support`, at both gating viewports and in both themes, axe-core reports
`scrollable-region-focusable` (serious, WCAG 2.1.1 Keyboard) on the matrix legend (`.legend` in
`website/src/components/SupportMatrix/styles.module.css`): it is a scroll container with no focusable
content and no `tabindex`, so a keyboard user cannot scroll it.

Fix direction (one line): make the legend wrap instead of scroll, or give it `tabindex="0"` and a label.

Severity S2: a gate 5 failure on one page; the matrix itself is readable.

## Closed in R-01

Red: with the waiver removed, `gate5 axe:scrollable-region-focusable` failed 2 units on
`/codespec/docs/reference/support`, none waived.

Fix: the legend's scroll box in `website/src/components/SupportMatrix/index.tsx` (a hand-written
component, not a generated file) is a focusable region: `tabIndex={0}`, `role="region"`,
`aria-label="Legend: cells per state and column"`, with a focus ring in `styles.module.css`.

Green: `scrollable-region-focusable` 0; `axe.serious` on the support page 0.
