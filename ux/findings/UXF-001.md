The site ships no search: the navbar holds the title, six links, GitHub and the theme toggle, and no
search box or search button on any of the 19 pages, at either gating viewport, in either theme. The
adapter lists search as always visible, so gate 2 fails on every page, and gate 5's "Tab reaches
search" fails with it.

Effect: a reader with a term (`codespec trace`, `TypeParam`) has to guess the page. The screen-only
user still reaches every task, through the navbar and the sidebar, at 10 actions for the two CLI tasks
(see `ux/rounds/R-01/report.md`).

Fix direction (one line): add a local search (no third-party service) to the navbar.

Severity S2: a hard gate fails on every page; no task is blocked.
