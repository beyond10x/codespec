At 390x844 the search input sits over the navbar toggle. A tap on the only button in the top right
focuses search. The menu with the navbar links and the docs sidebar doesn't open. Only search and
in-page links are left.

The report's measured-only table shows 84 always-visible misses at 390x844 and at 768x1024. I checked
the cover only at 390x844.

Fix direction (one line): give the mobile search box its own slot beside the toggle (navbar CSS in
`website/src/css/custom.css` or the docs-system theme).

Severity S2: on a phone the sidebar, the main way through the docs, can't be reached by touch. The
viewport isn't gated, so no gate fails.

Fixed in R-03: below 997px the search container sits 64px further left, beside the menu button.
