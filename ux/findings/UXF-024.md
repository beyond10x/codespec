UXF-014 raised code blocks to 14.4 px. Inline code is still 88 % of its parent, so in a 14.4 px
table cell it is 12.7 px. On the cir/1 reference and the CLI reference the field names, types,
commands and options are all inline code in tables: the data the reader came for is set smaller
than "yes", "no" and the descriptions next to it. Column headers are 10.9 px uppercase.

Effect: a reader scanning a reference table reads the smallest text on the page. Contrast passes
(axe 0 serious).

Fix direction (one line): set `.markdown td code` (and the support matrix's code) to 1em or 14 px in
`website/src/css/custom.css`.

Severity S3: readable, below the 14 px floor the heuristic sets.

Fixed in R-06: `website/src/css/custom.css` sets inline code in table cells and headers, and table headers, at 0.875rem; headers lose the uppercase and letter spacing. The support matrix component keeps its own sizes (UXF-021).
