# Story: The Rust writer writes a nil check on a shared pointer

## Outcome

`codespec-write-rust` writes a `cir/1` comparison of a pointer with nil, and a map lookup of a pointer
value that may be absent, instead of refusing them.

## Context

Found while building `examples/ledger` (story java-example-ledger, wave 2, 2026-11-06). The Java
idiom `map.get(k) == null` reads into exactly this form. The ledger was reshaped to avoid it: an
id → number `TreeMap` plus a `List`. Pre-existing limitation of the writer: `Expr::Nil` of any type
other than a slice or map is refused today (`adapters/rust/src/write.rs:2586-2589`).

`story:nullable-reference-fields` needs this form: a JVM reference field with no initializer reads
as `ptr(T)` with zero value `nil`, and its Rust output must write that pointer and its nil checks.

This story updates the Rust writer's `--describe` manifest claim (`adapters/rust/src/main.rs`, the
manifest `story:runners-and-manifests` adds) to claim the nil-pointer features it adds, and no
others.

## Acceptance

- A writer test: a document comparing a `*T` local, and the result of a map lookup of `*T`, with nil
  is written as Rust that compiles, and keeps the comparison's meaning (`Option` or an equivalent).
- A `*T` field whose zero value is `nil` is written, and reading it before assignment compares
  equal to nil.
- `codespec-write-rust --describe` claims the added features; `codespec` validates the manifest
  strictly.
- The orders, greeter, inventory, series and ledger outputs are unchanged.

## Scope

- `adapters/rust/src/write.rs`: the nil forms; tests in `adapters/rust/tests/writer.rs`.
- `adapters/rust/src/main.rs`: the `--describe` claim only, after `story:runners-and-manifests`.
- `website/data/conformance/`: the Rust writer's conformance report is regenerated there
  (`story:codespec-conform`, hence the edge), since the writer's claims and results change.
- `website/data/support-matrix.json`: regenerated by `codespec-docs` if `story:support-matrix` has
  landed; untouched otherwise.
- Shares `adapters/rust/src/write.rs` with `story:rust-writer-error-propagation`, which depends on
  this story and lands after it.
