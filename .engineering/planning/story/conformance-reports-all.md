# Story: A conformance report for every adapter

## Outcome

Every adapter in the repository has a codespec conform report in website/data/conformance/, generated by codespec-docs and drift-checked, so the support matrix colours every cell from a report: the Go and Rust readers and writers, the Java reader and the Groovy reader. Reader corpora come from the kit's per-language sources (case.go, rust/case.rs, java/Case.java) rather than from writer output. Requested by the operator on 2026-11-06 (100% everywhere).

## Acceptance

- website/data/conformance/ holds reader-go, reader-rust, reader-java, reader-groovy, writer-go and writer-rust reports; each conforms: true; task docs-check fails on drift.
- The Rust reader corpus is built from conformance/cases/*/rust/case.rs and the Java one from java/Case.java, not copied; a test fails when a case source and its corpus entry differ.
- Each report's claimed set equals the adapter's --describe claim.

## Scope

- conformance/reader/, crates/docs/src/, website/data/conformance/, crates/conformance/src/conform.rs (corpus layout only)
