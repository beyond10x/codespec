# Story: series Rust → cir/1 → Go under the harness

## Outcome

`examples/series` runs a fourth implementation: the Rust output read by `codespec-read-rust`,
passed and written as Go. The harness compares it with the original, the Go output and the Rust
output.

## Acceptance

- `task examples-series` reads `examples/series/out/rust` twice byte-equal, compares the document
  with a checked-in `examples/series/series.rust-read.cir.json`, writes it as Go and compares that
  with a checked-in `examples/series/out/go-from-rust/series.go` (gofmt-clean, vetted).
- `examples/series/harness.toml` lists the implementation `go-from-rust`; the harness reports 4
  implementations byte-equal on 200 seeds of 300 commands.
- The showcase page `/docs/examples/series` gains a section for the Rust → `cir/1` → Go direction,
  generated by `codespec-docs`; `task docs-check` holds it.

## Scope

- `examples/series/`: `series.rust-read.cir.json`, `out/go-from-rust/`, `harness.toml`,
  `drivers/go/overlay-go-from-rust.json`.
- `Taskfile.yml`: `examples-series`, `examples`.
- `crates/docs/src/series.rs`, `website/docs/examples/series.md`.
- `CHANGELOG.md`.
