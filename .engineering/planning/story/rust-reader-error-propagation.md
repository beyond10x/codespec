# Story: The Rust reader reads an error propagated with `?`

## Outcome

`codespec-read-rust` reads `let v = f()?;` and `f()?;` (a callee whose only error-carrying result
is a `Result<(), E>`) inside a function whose result is a `Result`, where `f` is a fallible
function of the same crate, as the `cir/1` propagation form the Rust writer writes with `?`, and
claims `sem.error.propagate`.

## Context

`story:rust-writer-error-propagation` writes the form as `?` and puts `sem.error.propagate` in the
Rust reader's `not` list, because the reader keeps `?` as `foreign` (`adapters/rust-read/src/lib.rs`,
the list of what is not read). The writer's own output is therefore not read back.

## Acceptance

- `conformance/cases/sem-error-propagate/rust/case.rs` holds the case in Rust with `?`;
  `adapters/rust-read/tests/cases.rs` reads it with no refusal and runs it as the reference, equal
  to `expected.txt`.
- `sem.error.propagate` is removed from the reader's `not` list and the doc table;
  `website/data/conformance/reader-rust.json` lists it claimed and `pass`.
- A reader test in `adapters/rust-read/tests/reader.rs`: the Rust writer's `?` output for the case
  reads back to the passed `case.cir.json`.
- A reader test: `f()?;` as a statement, on a callee returning `Result<(), E>`, reads with no
  refusal into the error-only propagation form (`err := f(); if err != nil { return …, err }`).
- A `?` on an `Option`, on a call of a function outside the crate, or in a function that does not
  return a `Result`, stays `foreign` with a refusal at its line: three reader tests, one each.
- Every checked-in `*.read.cir.json` and `*.rust-read.cir.json` that this story does not regenerate
  is byte-unchanged against its base.

## Scope

  `adapters/rust-read/tests/reader.rs`, `adapters/rust-read/tests/cases.rs` (if it needs an edit).
- `conformance/cases/sem-error-propagate/rust/case.rs`.
- `CHANGELOG.md`: one entry (shared with `story:jvm-readers-error-propagation`; the second merge
  keeps both entries).
- Regenerated by `task docs-generate`, never hand-edited: `conformance/reader/rust/`, all six
