- **Suite, after the cases existed:** AdversaryTest on head: 0 passed, 8 failed, exit 1. The same suite with the base reader (`159134e`, built into scratch): 8 passed, exit 0, so all 8 are introduced. ReaderTest on head: 50 passed, 0 failed, exit 0 (executed 50→50; the new cases sit in their own class).
- **Held (reads):** labeled `break`/`continue` (innermost loop, out of a switch, `while`/`for`/for-each); interface dispatch through params, fields and lambda captures; `errorf` with `%d`/`%s`/`%%`; `println` of byte, short, boolean, no argument and a tab; method references binding their receiver once; variadic calls with zero args and with an aliased array.
- **Held (refused by name):** varargs over `long[]...` and `Object...`, a null array, casts, `?:`, `instanceof`, `==` on objects, initializer blocks.
- **Held (union, claims, hostile input):** `READ_UNIONS = false` holds: the union is put and removed over the same `decls` loop, so nothing emits one. All 103 kit modules use their subject. 30 hostile packages gave no stack trace; each was refused with a reason or read correctly.
- **Held (runner, Groovy):** the runner's `Object` printing matches the Go reference for Long/Integer/Short/Byte/Boolean/String/enum/List. Double, Character, null and Map are refused (exit 2) on both sides. One mismatch: a `List<Object>` prints in Java but the Go runner refuses `[]any` (exit 2), so it fails loudly. Groovy reading is untouched: the only shared code that changed is `Runner.java`.
