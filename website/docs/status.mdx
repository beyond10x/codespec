This page describes release **0.1.0**: milestones M0, M1 and M4 of the [Vision](/docs/vision#milestones);
M4, the Rust reader, is decided and in progress.
The [changelog](https://github.com/beyond10x/codespec/blob/main/CHANGELOG.md) records every
user-visible change. **Shipped** means code in the release held by a named check: `codespec-docs`
generates this table from its capability list and fails when a test or gate task it names is gone.
**Decided** means part of the release scope but not in this tree yet; **planned** means a milestone
that is not built.

## Not provided

- **No network I/O or concurrency in `cir/1`.** Such code is kept as a `foreign`
  statement and refused by writers for another language.
- **No language model.** Nothing in the pipeline guesses; this is not planned.
- **No ESS integration.** Using an ESS conformance suite as an equivalence oracle is a direction
  in the [Vision](/docs/vision#later), not a plan.

## Known limitations

- **One reader in this tree.** Only Go can be read; the Rust reader, and with it Rust → `cir/1` →
  Go, is decided for 0.1.0 and in progress.
- **The harness speaks `orders`.** Its trace generator and drivers are the `orders` example's;
  `greeter` is checked by equality with its checked-in outputs and its builds.
- **The Rust writer refuses more than the Go writer.** It refuses a function holding a `foreign`
  statement, a loop over a map the facts do not list, an `error` result that is not `fallible`, and
  a write into a map entry's value (`m[k]++`); each lands in `refusals.json`.
- **Single-threaded Rust output.** Shared values are `Rc<RefCell<T>>` and channels of `any` are
  `std::sync::mpsc::Sender<Message>` drained by the caller.
